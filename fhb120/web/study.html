02

THREE DIRECTIONS

三条路径

PATH 01 / SYSTEMS

底层与系统

目标：底层计算机工程师、系统软件 / 内核 / 编译器 / 嵌入式方向。

C → 数据结构 → 四大件 → 编译原理

  • C 进阶：指针、内存管理、调试与性能工具
  • 汇编、数字逻辑、计算机体系结构
  • 操作系统内核、Linux 系统编程、并发
  • 编译原理：词法、语法、中间表示、优化与代码生成
  • 计算机网络、协议与性能分析（profiling）
  • 可选：C++/Rust、数据库内核、分布式系统

PATH 02 / INTELLIGENCE

AI 算法与基础设施

目标：AI 算法工程师，或 AI Infra 工程师。

数学 + Python → 机器学习 → 深度学习 → LLM

  • 数学、Python、NumPy、机器学习、深度学习
  • Transformer、LLM、模型训练与评估、论文复现
  • Infra：C++、操作系统、计算机网络
  • Infra：CUDA/GPU、分布式训练、推理部署与量化
  • Infra：容器、集群调度、性能分析与 MLOps

PATH 03 / EMBODIED

视觉、具身智能与机器人

目标：计算机视觉、VLA、具身智能或嵌入式 AI。

感知 → 理解 → 决策 → 动作 → 控制

  • 计算机视觉：图像处理、CNN、检测/分割、3D 视觉
  • 多模态与 VLA：ViT、Transformer、视觉-语言-动作
  • 机器人学习：强化学习、模仿学习、sim2real
  • 机器人与控制：坐标变换、运动学、ROS 2
  • 仿真：MuJoCo、Isaac Sim、Gazebo
  • 嵌入式：C/C++、传感器、实时系统、边缘部署
